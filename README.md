## Descrição

Plugin de **campos brasileiros para o checkout do WooCommerce**, facilitando e melhorando o fluxo de preenchimento dos dados nas páginas de checkout.

> Campos de Checkout:

- CPF e CNPJ com validação automática (incluindo CNPJ alfanumérico).
- Campo de número do endereço (com checkbox "Sem número").
- Campo de bairro.
- Telefone com máscara e DDI.
- Seletor de Pessoa Física / Pessoa Jurídica.
- Inscrição Estadual (IE).
- Data de nascimento e gênero.
- Preenchimento automático do endereço pelo CEP.
- Compatibilidade com o modo Legacy e Blocos (Gutenberg).

> **Nota:** A calculadora de frete (página de produto e carrinho) migrou para o plugin [Shipping Simulator for WooCommerce](https://wordpress.org/plugins/shipping-simulator-for-woocommerce/).

## Como instalar?

1. Acesse o painel de administração do WordPress e vá para **Plugins > Adicionar Novo**.
2. Pesquise por "Fields for Brazilian Checkout for WooCommerce".
3. Encontre o plugin, clique em **Instalar Agora** e depois em **Ativar**.
4. Pronto! Nenhuma configuração adicional é necessária.
