Shipping calculator for Brazilian WooCommerce stores with automatic Postal Code address pre-filling and Brazilian Market on WooCommerce.

== Description ==

Improved shipping calculator designed specifically for Brazilian e-commerce stores using WooCommerce.

= Key Features =

* ZIP Code Validation on Cart Page
* Automatic Address Lookup on Checkout
* CPF/CNPJ Fields with Validation
* Phone Masks for Brazilian Numbers

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/woo-better-shipping-calculator-for-brazil`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Configure via WooCommerce → Settings → Calculadora de frete

== Frequently Asked Questions ==

= How does the CEP lookup work? =

The plugin queries the ViaCEP API to autofill address fields based on the Brazilian postal code.
